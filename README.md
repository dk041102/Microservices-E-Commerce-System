# Microservices-E-Commerce-System
A scalable microservices-based E-commerce platform built using Node.js, Express, React, PostgreSQL, and Redis.
The project follows a modern backend architecture where each service runs independently and communicates through an API Gateway.

This system demonstrates real-world backend design used in production systems, including authentication, service communication, caching, and payment integration.

🚀 Features

🔐 JWT Authentication (Register / Login)

🛍 Product Management System

📦 Order Management

💳 Payment Integration (Razorpay)

📧 Email Notifications

⚡ Redis Caching for Faster APIs

🔗 API Gateway for routing requests

🧩 Microservices Architecture
