# Microservices-E-Commerce-System
A scalable microservices-based E-commerce backend system built using Node.js, Express, React, PostgreSQL, and Redis. The architecture includes independent services such as Auth, Product, Order, Payment, and Notification, all connected through an API Gateway.

The system supports JWT authentication, product management, order processing, payment integration (Razorpay), email notifications, and Redis caching for improved performance.
This project demonstrates microservices architecture, service communication, and scalable backend design similar to production systems.
